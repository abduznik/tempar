Welcome to TempAR [v1.70 released]

TempAR is a cheat engine plugin for the PlayStation Portable, supporting both CWCheat and PSP Action Replay (PSPAR) code types in a single plugin. It runs on custom firmware (CFW) as a kernel-mode plugin, with an in-game menu, a live memory search, a MIPS disassembler, and a memory browser — everything you need to use and create PSP cheat codes.

Features
Dual Cheat Engine — CWCheat and PSP Action Replay (PSPAR + Extended) codes, loaded from the same database. PSX GameShark Support — compatibility with PS1-on-PSP (POPS) titles via a dedicated lite build.
Memory Search — 8/16/32-bit exact & unknown value search; add results as new cheats instantly. MIPS Disassembler — inspect and patch live game memory on-device with a built-in browser/decoder.
NitePR / PSPAR.com Compatible — load existing NitePR .txt and PSPAR.com .bin cheat files, no conversion needed. Skinnable & Multi-language — customize UI colors, pick from several translated language packs.
Quick Start
  1. Grab the latest release from the downloads page.
  2. Copy the seplugins folder to your Memory Stick.
  3. Press R+HOME in-game to open the cheat menu.

Full steps, all hotkeys, and cheat file formats: see Install & Hotkeys.

Lineage

TempAR is a heavily modified descendant of MKUltra, itself a modified descendant of NitePR — carrying PSP cheat-device history forward from the CWCheat/PSPAR era while adding features neither predecessor had: favorites, extended PSPAR code types, PSX GameShark support, and a multi-language UI.
