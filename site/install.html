Installation
  1. Download the latest release from the downloads page.
  2. Copy the seplugins folder to the root of your PSP's Memory Stick.
  3. If you're not already copying over game.txt and pops.txt, manually add the plugin lines to your existing files.
  4. Choose tempar.prx for the full build, or tempar_lite.prx for POPS (PS1-on-PSP) / memory-constrained modes.

See the Downloads page for full vs. lite build details.
